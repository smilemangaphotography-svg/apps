# ShishaLove Mobile 1.0

Production mobile wrappers for the live ShishaLove WordPress/WooCommerce platform.

## Canonical release branch

`shishalove-main`

WordPress/WooCommerce remains the single source of truth for products, categories, stock, prices, orders, customer data and merchant writes. The mobile apps never maintain an independent catalogue.

## Android

- **ShishaLove Customer** — `eu.shishalove.customer` — version `1.0.0`
  - opens `https://shishalove.eu/shishalove-app/`
  - persistent cookies/cart/account session
  - internal ShishaLove links stay in-app; external links open in the system browser
- **ShishaLove Merchant** — `eu.shishalove.merchant` — version `1.0.0`
  - opens `https://shishalove.eu/shishalove-merchant/`
  - WordPress login/wp-admin remain in the same WebView so authentication persists
  - image/file-library upload support

The release workflow always validates both Android apps. Store signing is intentionally not committed to the public repository. Configure a private Android release keystore before Play Store publication. Development/install APKs can still be generated by CI for device testing.

## iPhone / iOS

Native iOS Customer and Merchant wrappers live under `shishalove-ios/` and use `WKWebView` with the same live URLs and cookie/session model.

- Customer bundle ID: `eu.shishalove.customer`
- Merchant bundle ID: `eu.shishalove.merchant`
- minimum deployment target: iOS 16

The iOS project can be generated with XcodeGen using `shishalove-ios/project.yml`. CI performs an unsigned simulator build to catch compilation problems. Installing on physical iPhones or distributing through TestFlight/App Store requires an Apple Developer team, signing certificate and provisioning profile; those credentials must remain private and are not stored in GitHub.

Until native iOS signing is configured, both live web apps can also be installed immediately on iPhone from Safari using **Share → Add to Home Screen**.

## WordPress bridge

The finalized bridge is version `1.0.0`, based on approved beta `0.7.6`. Release metadata is stored under `shishalove-wordpress-bridge/`.
