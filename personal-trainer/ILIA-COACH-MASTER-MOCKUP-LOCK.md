## Approved onboarding sequence
The approved master mockup is now the implementation specification for onboarding.

1. Welcome / cover
2. Goals
3. Quick presets
4. Body emphasis
5. Joint priority
6. Running / race (optional)
7. Experience
8. Availability / schedule / equipment
9. Nutrition (optional)
10. Summary / Create My Plan

The visible layout must stay premium, cream/dark/lime, safe-area compliant and phone-first.

## Functional lock
Every visible control must be real and persistent. No fake cards, dead buttons or decorative selectors.

### Goals
Multiple goals may coexist. A user may prioritize upper-body development while also prioritizing legs, running or recovery. One race distance may be active at a time.

### Quick presets
Presets are editable starting points only:
- Balanced
- Upper + Strong Legs
- Upper Body
- Legs First
- Knee Support + Strength
- Runner + Leg Strength

### Body emphasis
Each area is independent:
- Chest
- Back
- Shoulders
- Arms
- Quads
- Glutes
- Hamstrings
- Calves
- Core

Each has four functional levels:
- MINIMAL
- MAINTAIN
- FOCUS
- PRIORITY

Body emphasis affects exercise selection/order and program emphasis. PRIORITY can increase volume where guardrails allow.

### Joint priority
Each supported area has OFF / SUPPORT / PRIORITY:
- Knee
- Hip
- Ankle
- Lower Back
- Shoulder
- Elbow
- Wrist

SUPPORT weaves compatible capacity work into relevant training. PRIORITY may add a dedicated capacity block. Injury guardrails always take precedence.

### Running
Optional race choices:
- 5K
- 10K
- Half Marathon
- Marathon
- No race goal

Race target date/time persist into the program state and existing running engine.

### Experience
Beginner / Intermediate / Advanced / Elite persist and are visible in Review.

### Availability
Training days, session duration and equipment are functional inputs to program generation.

### Nutrition
Balanced Eating / High Protein / Calorie Deficit / Performance Fuel / Set Later persist as the user's nutrition focus without blocking program creation.

### Review
The final screen must visibly summarize goals, body emphasis, priority areas, joint support, running target, experience, schedule/equipment and nutrition before `CREATE MY PLAN`.

## Do-not-touch lock
Existing Home / Plan / Train / Fuel / More behavior, exercise media, running GPS/voice bridge, admin tools, local persistence and Android package identity remain frozen unless a required compatibility fix is necessary.
